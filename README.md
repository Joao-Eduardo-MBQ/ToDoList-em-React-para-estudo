# Lista de Tarefas (React)

Aplicação simples de **lista de tarefas** feita em **React** para praticar componentes, estados e manipulação de dados.

## Funcionalidades

* Adicionar tarefas
* Definir categoria
* Definir prazo
* Marcar tarefa como concluída
* Deletar tarefas
* Buscar tarefas
* Filtrar por categoria
* Dark mode

## Tecnologias

* React
* JavaScript
* CSS

Projeto feito para **estudo e prática de React**.
